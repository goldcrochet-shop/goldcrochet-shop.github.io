🔑 Token Pessoal do GitHub

O painel administrativo usa o GitHub Personal Access Token (PAT) para criar os arquivos HTML individuais de cada produto, salvar o catálogo data.json e enviar fotos direto para o repositório, sem precisar de servidor localhost.

Gere em: GitHub > Settings > Developer Settings > Personal Access Tokens > Tokens (classic) marcando a opção repo.
